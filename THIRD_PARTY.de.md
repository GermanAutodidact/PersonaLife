# Drittquellen und Zuordnung

[English](THIRD_PARTY.md)

Der Implementierungscode von PersonaLife wurde eigenständig geschrieben und steht unter Apache-2.0. Implementierungscode der recherchierten Repositories wurde weder kopiert noch mitgeliefert. Quellen, geprüfte Pfade und Prüfsummen stehen im [Recherchevergleich](docs/research-comparison.de.md) und in `docs/source-evidence.json`.

| Projekt | Beobachtete Lizenz | Verwendung | Zuordnung und Weitergabe |
|---|---|---|---|
| Canon-73/crescent-grove | MIT | Referenz für Heartbeat und Zustandskontinuität | Als Recherchequelle genannt; kein kopierter Code |
| Yuralume/yuralume-core | BUSL-1.1 | Referenz für Planung und Änderungen nach Gesprächsrunden | Kein kopierter Code; keine Behauptung uneingeschränkt freier Wiederverwendung |
| ddkhan24/hordestudio | Keine eindeutige Hauptlizenz gefunden | Referenz für Aktivitäten, Aufmerksamkeit und Fortschritt | Kein kopierter Code |
| ericwang915/HerAndHim | AGPL-3.0 | Referenz für berufs- und datumsabhängige Tagesplanung | Kein kopierter Code und keine Verknüpfungsabhängigkeit |
| joonspk-research/generative_agents | Apache-2.0 | Aktualität, Wichtigkeit, Relevanz und Reflexion | Als Recherchequelle genannt; kein kopierter Code |
| mem0ai/mem0 | Apache-2.0 | Adapter für optional bereitgestellten Client | Das SDK wird nicht im Repository verteilt |
| letta-ai/letta | Apache-2.0 im aktuellen Hauptzweig | Zustandsbehaftete Agenten und optionale bereitgestellte Brücke | Die frühere Implementierung wird nicht mitgeliefert |
| GermanAutodidact/AiMemory | Apache-2.0 | Optional installierter Erinnerungsanbieter; tatsächliche API-Integrationstests | Separat installiertes Paket; keine mitgelieferte Implementierung |

Python-Standardbibliothek und ihre Bestandteile behalten ihre eigenen Lizenzen. Unter Windows kann das separat verteilte Paket `tzdata` die IANA-Zeitzonendaten bereitstellen. Der enthaltene Apache-2.0-Text ist die Standardlizenz, keine übernommene Implementierung. [LICENSE](LICENSE) bleibt als unveränderter englischer Originaltext maßgeblich; diese Seite erläutert die Zuordnung auf Deutsch.
